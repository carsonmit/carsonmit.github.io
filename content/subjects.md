# Tutoring subjects

The list of subjects shown in the Tutoring section of the site.
Edit this file any time to add or remove a subject; nothing else needs to change.

How to edit:
- One subject per line, starting with "- ".
- Optional: group subjects under a heading that starts with "## " (for example "## College").
- Lines that don't start with "- " or "## " (like these instructions) are ignored by the site.
